# 📌 Project Overview

The **Library Management System** is a relational database project built using **MySQL**. It helps manage library operations such as maintaining book records, member information, employee details, book issuing, and returns.

The project demonstrates database design concepts including **DDL, DML, DQL, Constraints, Joins, Aggregate Functions, Views, and SQL Queries**.

---

# 🎯 Project Objectives

- Design a relational database for library operations.
- Store and manage books, members, and employee information.
- Track issued and returned books.
- Perform data analysis using SQL queries.
- Demonstrate MySQL database concepts.

# ▶️ How to Run

1. Install **MySQL Server** and **MySQL Workbench**.
2. Open **MySQL Workbench**.
3. Create a new database.
4. Execute **DATABASE.sql** to create the database schema.
5. Execute **INSERT_DATA.sql** to insert sample records.
6. Execute **QUERIES.sql** to test and analyze the database.
7. Verify the outputs using MySQL Workbench.
