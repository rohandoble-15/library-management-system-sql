# 📚 Library Management System (MySQL)

## 📌 Project Overview
The Library Management System is a MySQL database project designed to manage library operations such as maintaining book records, member details, employee information, and book issue/return transactions.

This project demonstrates fundamental and intermediate SQL concepts, making it suitable for beginners and Data Analyst portfolios.

---

## 🛠️ Technologies Used
- MySQL
- MySQL Workbench
- SQL

---

## 📂 Database Tables

1. Branch
2. Employee
3. Books
4. Members
5. Issue_Status

---

## 📋 Features

- Store library branch information
- Manage employee records
- Manage book inventory
- Register library members
- Issue and return books
- Calculate fines
- Track overdue books
